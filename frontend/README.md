# Cortex Companion Frontend

Estrutura base de um aplicativo React Native moderno alinhado a práticas OWASP Top 10.

## Scripts disponíveis

- `yarn start` ou `npm run start`
- `yarn android` / `yarn ios`
- `yarn test`
- `yarn lint`

## Estrutura

```
src/
  components/
  screens/
  hooks/
  services/
  constants/
  features/
  assets/
  tests/
```

As responsabilidades foram organizadas para preservar a separação entre UI, regras de negócio local e integrações com APIs seguras.
